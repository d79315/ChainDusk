# ChainDusk

ChainDusk enables real-time, event-driven data synchronization across a distributed system, utilizing auto-scaling architecture.

ChainDusk is built to be simple and practical, focusing on doing one thing well.

**Why ChainDusk?**

- ChainDusk enables real-time, event-driven data
- synchronization across a distributed system,
- utilizing auto-scaling architecture

## Key Features

- ChainDusk enables real-time, event-driven data

- utilizing auto-scaling architecture

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainDusk.git`
2. `cd ChainDusk`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainDusk is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
